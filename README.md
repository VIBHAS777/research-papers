## 🔬 Detailed Paper Descriptions

### [5] Enhancing CPU Benchmark Scores Using RNN-Based Deadlock Detection from System Logs
- **Conference:** 16th International Conference on Computing, Communication and Networking Technologies (ICCCNT 2025), IIT Indore
- **Authors:** Irigela Bharghava Vardhan Reddy, Hima Sagar B, Aiswariya Milan K, Araveeti Vibhas Reddy, Hemanth Alla
- **Directory:** [`05-RNN-Based-Deadlock-Detection/`](./05-RNN-Based-Deadlock-Detection/)
- **Summary:** Applied recurrent neural networks (RNNs) for automated deadlock detection in real-time system logs, enhancing CPU benchmark score efficiency by eliminating pipeline stalling and resource contention.

---

### [6] Optimization of Space Shuttle External Tank Design Return on Investment (ROI)
- **Conference:** International Conference on Advances and Applications of Numerical Analysis (ICAANA 2025), Amrita Vishwa Vidyapeetham, Coimbatore
- **Authors:** Dhimant Kulkarni, Hima Sagar B, Araveeti Vibhas Reddy, Mamatha T M
- **Directory:** [`06-Space-Shuttle-External-Tank-ROI/`](./06-Space-Shuttle-External-Tank-ROI/)
- **Summary:** Developed a data-driven numerical framework combining SLSQP constrained optimization and regression modeling to optimize tank dimensions, material properties, and structural constraints for maximizing ROI while adhering to safety thresholds.

---

### [7] Automated Medical Image Analysis for Brain Tumor and Skin Disease Diagnosis Using Transfer Learning and Grad-CAM
- **Conference:** 3rd International Conference on Information Technology, Electronics and Intelligent Communication Systems (ICITEICS 2026)
- **Authors:** Araveeti Vibhas Reddy, Hima Sagar B, Irigela Bharghava Vardhan Reddy, S Pavan Kumar, Nalini Sampath
- **Directory:** [`07-Automated-Medical-Image-Analysis-Grad-CAM/`](./07-Automated-Medical-Image-Analysis-Grad-CAM/)
- **Summary:** Implemented transfer learning architectures integrated with Gradient-weighted Class Activation Mapping (Grad-CAM) for visual explainability in automated multi-domain medical diagnosis (brain MRI scans and dermatological lesion images).

---

### [8] AI-Driven Load Balancer with Blockchain-Based Decision Making in Banking System
- **Conference:** 10th International Conference on Electronics, Communication and Aerospace Technology (ICECA 2026)
- **Authors:** Hima Sagar B, A Vibhas Reddy, S Pavan Kumar, Sreebha Bhaskaran, Shinu M. Rajagopal
- **Directory:** [`08-AI-Driven-Load-Balancer-Banking/`](./08-AI-Driven-Load-Balancer-Banking/)
- **Summary:** Proposed an intelligent load-balancing architecture using decentralized blockchain consensus for tamper-proof, high-throughput transaction routing across distributed core banking nodes.

---

### [9] Stability Threshold and Performance Degradation Analysis of Priority-Aware SDN in Healthcare IoT Systems
- **Conference:** International Conference on Ubiquitous Intelligence and Systems (ICUIS 2026)
- **Authors:** A Vibhas Reddy, S Pavan Kumar, Thangam S
- **Directory:** [`09-Priority-Aware-SDN-Healthcare-IoT/`](./09-Priority-Aware-SDN-Healthcare-IoT/)
- **Summary:** Analyzed stability margins and QoS degradation under extreme traffic spikes in software-defined network (SDN) topologies designed for mission-critical medical IoT devices.

---

### [10] Intelligent Congestion Prediction and Control in Data Center Networks Using SDN and Deep Learning
- **Conference:** International Conference on Networks (ICON INDIA 2026)
- **Authors:** Vibhas Reddy A, Pavan Kumar S, Hima Sagar B
- **Directory:** [`10-SDN-Deep-Learning-Congestion-Control/`](./10-SDN-Deep-Learning-Congestion-Control/)
- **Summary:** Built a proactive traffic management system coupling deep learning time-series congestion forecasting with OpenFlow SDN controllers to prevent buffer overflow and reduce packet loss in cloud data centers.

---

### [11] A Unified Machine Learning Pipeline for Early Prediction of Heart Disease, Diabetes Mellitus, and Alzheimer’s Disease
- **Conference:** International Conference on Recent Trends in Advanced Computing (ICRTAC 2026)
- **Authors:** Araveeti Vibhas Reddy, Hima Sagar B, Irigela Bharghava Vardhan Reddy, S Pavan Kumar, Nalini Sampath
- **Directory:** [`11-Unified-Chronic-Disease-Prediction-Pipeline/`](./11-Unified-Chronic-Disease-Prediction-Pipeline/)
- **Summary:** Designed an end-to-end multi-disease machine learning pipeline utilizing disease-specific preprocessing, SMOTE class balancing, and feature optimization for early risk prediction.

---

### [12] A Low-Cost Real-Time Multimodal Seizure Detection System Using MAX30102 and Accelerometry
- **Conference:** International Conference on Advanced Computing and Software (ICACS 2026)
- **Authors:** S Pavan Kumar, A Vibhas Reddy, Hima Sagar B, Meena Belwal
- **Directory:** [`12-Multimodal-Seizure-Detection-MAX30102/`](./12-Multimodal-Seizure-Detection-MAX30102/)
- **Summary:** Engineered a low-power, wearable seizure detection hardware device using MAX30102 PPG pulse oximetry, MPU6050 accelerometer sensors, and physiological threshold fusion algorithms to eliminate false positives.
